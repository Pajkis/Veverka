# Veverka Changelog v0.10.0

### 📅 Date: 2025-08-20

### 🔖 Git Version: v0.10.0

### 📦 Area: [Initial Release]

### 📝 Description:

> First public release of the Veverka project. Playable Sokoban-style puzzle game with grid-based mechanics, menus, audio, and Android/Windows support.

### ➕ Added:

- Core grid-based movement and pushable object mechanics.
- Level system with loading and 10 prepared levels.
- Undo functionality.
- ScriptableObject configs for gameplay and display settings.
- Audio system (music + sound effects).
- Scene flow system
- Menus: main menu, in-game menu, scene transitions.
- Builds for Windows and Android 12+.
